Before you read the data — read this

VAERS is the U.S. Vaccine Adverse Event Reporting System. Anyone can file a report. A report says someone had a health event after a vaccine and chose to report it — not that the vaccine caused it.

  • Counts of reports, not rates. There is no denominator here; you cannot turn a count into a true rate from this file.
  • Correlation is not causation. A report is a temporal association, unverified.
  • Counts are a floor. Most events are never reported; a bigger count is not a more dangerous vaccine.
  • Hypothesis-generating only. Good for spotting questions worth investigating — never for proving cause.
  • Leads, not verdicts. The clinician / epidemiologist owns the "why." Every decision belongs to a person and their clinician.

This screen records that you have read these terms; it is not an access control. If this tool is hosted behind a sign-in, that gate is enforced by the host site, not by this page.
